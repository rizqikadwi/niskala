# 🌐 Market Intelligence Globe

A lightweight, single-page web application that visualizes geopolitical news 
as a **cause-and-effect graph** on an interactive 3D globe, powered by a 
[Langflow](https://langflow.org) backend workflow.

Built with **vanilla HTML/CSS/JS** — no frameworks, no build step, no npm.

---

## ✨ Features

- 🌍 **3D interactive globe** (Mapbox GL JS v3)
- 📰 **Event markers** from news analysis (color-coded by severity)
- 🏢 **Company markers** for affected tickers (green = benefited, red = harmed)
- 🔗 **Cause-effect lines** connecting events to companies
- 🚢 **Strategic chokepoint overlay** (Hormuz, Malacca, Suez, etc.)
- 📊 **Tabbed side panel**: Report / Events / Tickers
- 📈 **Mini metrics dashboard**: signal strength, event count, ticker count
- 🎨 **Dark theme** inspired by Bloomberg terminal
- 📱 **Responsive** for mobile
- ⌨️ **Keyboard shortcut**: `Ctrl+Enter` to run analysis
- 🔒 **Optional Node.js proxy** for production (hides API key)
